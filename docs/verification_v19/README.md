# Retained development evidence

These are frozen development records, not the completed publication sample.
Stage-status files describe what had been verified or planned at the time they
were written. Final findings use the 440 main runs and two 40-run follow-ups.

The compact learning, mechanism and confirmation ledgers retain favorable and
unfavorable trials. The forecast directories preserve training-only calibration
protocols, fitted coefficients and error summaries; the acceptance tests compare
the active setting overlays against those protocols. The critic summary supports
the DDPG calibration discussion.

Per-trial configurations, trajectories, logs and earlier verification directories
have moved out of the working tree. Their exact original paths and content
hashes are in [the cleanup manifest](../cleanup_manifest.json), with local Git
recovery instructions in [cleanup.md](../cleanup.md). Paths embedded in these
frozen records refer to that archived development snapshot. Do not rewrite the
records to make historical paths or status claims appear current.
